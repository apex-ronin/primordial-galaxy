## 3. Portfolio Project Case Study: "GovTech Hunter"

**Title:** Autonomous Intelligence & Active Defense System

**The Challenge:**
How do you protect a $600B federal procurement pipeline from a new wave of "Prompt Kiddies"—threat actors using AI to automate fraud and identity theft?

**The Solution:**
I architected and deployed "GovTech Hunter," an autonomous agent that aggregates state and federal RFP data, analyzes it for fit using Dual-Track AI (White Hat/Red Hat), and generates protective compliance clauses in real-time.

**Technical Highlights:**

* **Multi-Source Agnostic Scraping:** Built scrapers for SAM.gov (Federal) and CSDA (State), including API reverse-engineering of SPA interfaces.
* **Adversarial Simulation:** Created a Red Team module that uses LLMs to identify "Billing Fraud" and "Outsourcing Risk" in live contracts.
* **Self-Healing Orchestrator:** Implemented a resilient execution layer that monitors agent health and skips stalled modules without crashing the system.
* **Anonymized Reporting:** Automated the generation of professional whitepapers and risk mitigation memos for government stakeholders.

**The Result:**
A system that identifies high-value opportunities in < 3 minutes for < $0.10 in API costs, while simultaneously providing the defense clauses needed to "immunize" the contract against the very AI used to find it.
